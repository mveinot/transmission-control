The useful bits

Daily torrent management, thoughtfully assembled.

Planetary keeps common actions immediate and makes deeper controls available when you need them. Capabilities adapt to the server you are connected to, without turning the interface into a wall of switches.

↯

Add torrents from wherever they arrive

Open torrent files, paste a magnet link directly into the main window, use an add-options dialog, register Planetary as a file or magnet handler, or let a watch folder submit files automatically.

⌘

Three back ends, one interface

Save multiple Transmission, qBittorrent, and Deluge servers and move between them without learning a different client for each daemon.

◫

Every useful detail

Browse files, piece progress, peers, trackers, properties, transfer statistics, and session information in purpose-built views.

◎

Fine-grained transfer control

Start, stop, verify, reannounce, reorder queues, relocate data, choose files, set priorities, and adjust per-torrent limits where the connected server supports them.

⚑

Organize and find quickly

Search by name, filter by state, tracker, or folder, work with labels and groups, and search within an individual torrent's file tree.

◌

Status at a glance

See aggregate rates, torrent counts, free disk space, alternative-speed state, refresh cadence, and a live session overview without opening another tool.

◇

Desktop-aware notifications

Choose alerts for added, completed, stalled, and error states, delivered through native notifications or an external command. Built-in update checks present release notes inside the app.

≡

Private by design

Planetary includes no telemetry. Optional peer-country lookup uses a bundled local GeoIP database, so addresses are not sent to a lookup service.

A closer look

Designed for information, not spectacle.

The interface stays familiar to Transmission Remote GUI users while taking advantage of a modern Qt foundation and native platform behavior.

Why Planetary?

A continuation of a good idea.

Transmission Remote GUI set a high bar for remotely managing Transmission from a desktop. Planetary began as a modern C++ and Qt reimplementation and has grown into a multi-backend client for Transmission, qBittorrent, and Deluge.

It remains intentionally focused: make transfer management efficient, expose useful information, respect the desktop, and stay out of the way.

Platform note: macOS is currently the polished, distributed release and is available as a universal app for macOS 13 or later. The codebase also builds on Windows and Linux, but those platforms have not yet received the same release and refinement work.
