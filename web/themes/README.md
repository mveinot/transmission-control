# Planetary theme downloads

The `packages/` directory contains the individually downloadable
`.planetarytheme` files showcased on the Planetary website. Each package is a
ZIP-compatible archive that Planetary can open directly, or install from
Settings → Appearance.

Icon and colour components are independent. All packages are colour-only
except Flat Dark, Flat Light, Polar Night, Celestial Enamel, Orbital Console,
Keycap Terminal, Copper Relay, and Studio Console, which also supply icons.
Missing icons fall back to the built-in Glass theme, and hover artwork is
generated by Planetary at runtime.

| Terminal Green | Green phosphor palette inspired by monochrome text consoles; pair with Keycap Terminal icons |
| Verdant CRT | Soft forest-black and green-phosphor palette with organic activity accents |

The original palettes provide the colour vocabulary. Their mapping onto Qt's
application palette and Planetary's torrent-specific semantic roles is a
Planetary adaptation.
