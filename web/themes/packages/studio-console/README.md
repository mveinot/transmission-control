# Studio Console

Studio Console brings the feel of a well-used broadcast mixing desk to
Planetary: graphite surfaces, satin metal, warm amber accents, and tactile
bitmap toolbar controls. Each toolbar control has a raised resting image and a
matching recessed image while pressed. Other icon roles fall back to Planetary's
built-in Glass set. Older Planetary versions show the resting artwork and ignore
the optional pressed-state section.
